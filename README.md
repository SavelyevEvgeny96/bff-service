# Notepad Window Automation

Небольшое Windows-приложение на Kotlin/JVM. После запуска оно:

1. несколько раз переключается между открытыми окнами сочетанием `Alt+Tab`;
2. делает случайные паузы между переключениями;
3. читает исходный текстовый файл и помещает его содержимое в буфер обмена;
4. открывает целевой файл в Блокноте, вставляет текст, сохраняет файл и закрывает Блокнот.

## Требования

- Windows с графическим рабочим столом;
- JDK 21;
- Apache Maven (или входящий в проект Maven Wrapper).

Во время работы не используйте клавиатуру и мышь: приложение отправляет настоящие системные сочетания клавиш активному окну.

## Сборка и тесты

```bash
./mvnw clean test
./mvnw package
```

## Запуск

```powershell
java -jar target/notepad-window-automation.jar `
  --source "C:\automation\source.txt" `
  --output "C:\automation\result.txt"
```

Или через Maven:

```powershell
./mvnw exec:java -Dexec.args='--source "C:\automation\source.txt" --output "C:\automation\result.txt"'
```

Дополнительные параметры:

- `--switches 3` — количество переключений `Alt+Tab` (по умолчанию 3);
- `--min-delay-ms 500` — минимальная случайная пауза (по умолчанию 500 мс);
- `--max-delay-ms 1500` — максимальная случайная пауза (по умолчанию 1500 мс);
- `--notepad-wait-ms 1200` — ожидание запуска Блокнота (по умолчанию 1200 мс).

Исходный файл должен существовать. Каталог целевого файла также должен существовать. Если целевой файл уже есть, Блокнот перезапишет его новым содержимым.
